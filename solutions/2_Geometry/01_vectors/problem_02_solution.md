### Solution 2. Distance as the Length of a Vector

Given:

A = (1, 2, 3)

B = (4, -2, 6)


Step 1. Construct vector AB.

To find vector AB, subtract the coordinates
of A from the coordinates of B.

AB = B - A

AB = (4 - 1, -2 - 2, 6 - 3)

Therefore:

AB = (3, -4, 3)


Step 2. Calculate the length of vector AB.

The length of a vector in three dimensions is:

|AB| = sqrt(x^2 + y^2 + z^2)

Substitute the coordinates:

|AB| = sqrt(3^2 + (-4)^2 + 3^2)

|AB| = sqrt(9 + 16 + 9)

|AB| = sqrt(34)

Therefore:

|AB| = sqrt(34)


Step 3. Calculate the distance using the coordinate formula.

The distance between two points is:

d(A,B) = sqrt((x2-x1)^2 + (y2-y1)^2 + (z2-z1)^2)

Substitute the coordinates:

d(A,B) = sqrt((4-1)^2 + (-2-2)^2 + (6-3)^2)

d(A,B) = sqrt(3^2 + (-4)^2 + 3^2)

d(A,B) = sqrt(9 + 16 + 9)

Therefore:

d(A,B) = sqrt(34)


Step 4. Compare both calculations.

Using the vector length:

|AB| = sqrt(34)

Using the distance formula:

d(A,B) = sqrt(34)

Both calculations give exactly the same result.


Final Answer:

AB = (3, -4, 3)

|AB| = sqrt(34)

d(A,B) = sqrt(34)

Approximate distance:

d(A,B) = 5.83


Conclusion:

The distance between two points is equal
to the length of the vector connecting them.

Both methods use the same coordinate differences.

Therefore, the point-distance formula comes
directly from the length of a difference vector.
