### Solution 15. Classifying Three Systems

SYSTEM 1

Given:

x + y = 2
x - y = 0


Step 1. Add the two equations.

(x + y) + (x - y) = 2 + 0

2x = 2

x = 1


Step 2. Find y.

Substitute x = 1 into the first equation:

1 + y = 2

y = 1


Final classification:

The system has exactly one solution.

(x, y) = (1, 1)



SYSTEM 2

Given:

x + y = 2
2x + 2y = 4


Step 1. Eliminate the second equation.

Subtract 2 times the first equation from the second equation:

R2 = R2 - 2R1

The result is:

0 = 0


Step 2. Interpret the result.

The second equation is simply twice the first equation.

Therefore, both equations represent the same line.

There are infinitely many solutions.

The general solution is:

Let y = t.

x = 2 - t
y = t

Final classification:

The system has infinitely many solutions.



SYSTEM 3

Given:

x + y = 2
2x + 2y = 5


Step 1. Eliminate the second equation.

Subtract 2 times the first equation from the second equation:

R2 = R2 - 2R1

The result is:

0 = 1


Step 2. Interpret the result.

The statement 0 = 1 is impossible.

Therefore, the equations contradict each other.

The system has no solution.

Final classification:

The system is inconsistent.



FINAL COMPARISON

SYSTEM 1:
- Classification: One solution.
- Solution: (x, y) = (1, 1).
- Reason: Both variables have unique values.

SYSTEM 2:
- Classification: Infinitely many solutions.
- Reason: The second equation is a multiple of the first equation.

SYSTEM 3:
- Classification: No solution.
- Reason: Elimination produces the impossible statement 0 = 1.


CONCLUSION

There are three possible outcomes when solving a system
of linear equations:

1. One solution: A unique pair of values satisfies all equations.

2. Infinitely many solutions: The equations represent
   dependent conditions and do not determine a unique pair.

3. No solution: The equations contradict each other.

The elimination method allows us to recognize all three
cases by examining the resulting equations.
