### Solution 12. Homogeneous System

Given:

x + 2y - z = 0
2x + 4y - 2z = 0
x - y + 2z = 0


Step 1. Eliminate the second equation.

Subtract 2 times the first equation from the second equation:

R2 = R2 - 2R1

The second equation becomes:

0 = 0

Therefore, the second equation does not provide new information.

The remaining system is:

x + 2y - z = 0
x - y + 2z = 0


Step 2. Eliminate x.

Subtract the first equation from the second equation:

(x - y + 2z) - (x + 2y - z) = 0

-3y + 3z = 0

Therefore:

y = z


Step 3. Find x.

Substitute y = z into the first equation:

x + 2z - z = 0

x + z = 0

Therefore:

x = -z


Step 4. Write the parametric solution.

Let z = s, where s is any real number.

Then:

x = -s
y = s
z = s

The general solution is:

(x, y, z) = (-s, s, s)

where s is any real number.


Final Answer:

All solutions are given by:

x = -s
y = s
z = s

where s belongs to the real numbers.


Conclusion:

The zero vector (0, 0, 0) always satisfies a homogeneous
system because every equation has zero on the right-hand side.

Substituting x = 0, y = 0 and z = 0 makes every equation
equal to zero.

Therefore, a homogeneous system always has at least
one solution: the trivial solution.
