### Solution 14. A Small Change in the Right-Hand Side

Given two systems:

SYSTEM 1:

x + y = 2
2x - y = 1
3x = 3


Step 1. Solve the first two equations.

Add the first and second equations:

(x + y) + (2x - y) = 2 + 1

3x = 3

Therefore:

x = 1


Step 2. Find y.

Substitute x = 1 into the first equation:

1 + y = 2

y = 1


Step 3. Check the third equation.

3x = 3

3(1) = 3

3 = 3

The third equation is satisfied.

Therefore, SYSTEM 1 is consistent and has exactly one solution:

(x, y) = (1, 1)


SYSTEM 2:

x + y = 2
2x - y = 1
3x = 3.1


Step 4. Solve the first two equations again.

Adding the first and second equations:

3x = 3

Therefore:

x = 1

Substitute into the first equation:

1 + y = 2

y = 1


Step 5. Check the third equation.

3x = 3.1

3(1) = 3.1

3 = 3.1

This statement is false.

Therefore, SYSTEM 2 has no solution and is inconsistent.


Final Comparison:

SYSTEM 1:
- Consistent system.
- Exactly one solution.
- Solution: (x, y) = (1, 1).

SYSTEM 2:
- Inconsistent system.
- No solution.


Conclusion:

A small change in the right-hand side can change
the consistency of a system.

In the first system, all three equations agree
with the same solution.

In the second system, the first two equations require
x = 1, but the third equation requires x = 3.1/3.

These conditions contradict each other.

Therefore, even a small numerical change can make
a previously consistent system inconsistent.
